### 🚀 About Me

Frontend developer and senior Computer Science student focused on building reliable, responsive web applications with React, Next.js, and TypeScript. Experienced in REST API integration, commercial software delivery, Dockerized deployment, and CI/CD workflows.

🔭 &nbsp;I'm currently working on **a production ERP platform, where I am responsible for frontend development, API integration, deployment, and CI/CD.**  

🌱 &nbsp;I'm currently learning **data science, machine learning, and AI engineering principles, with a focus on Python, model development, evaluation, and the principles behind production-ready AI systems.**

### 💼 Featured Projects

#### 🏢 ERP System — Commercial Client Project

A production-deployed, Arabic-first business management platform covering sales, purchasing, inventory, finance, human resources, reporting, and role-based workflows.

- Led frontend development using **Next.js, React, and TypeScript**
- Built responsive RTL interfaces, reusable components, validated forms, dashboards, and data tables
- Integrated the frontend with **Spring Boot REST APIs**
- Managed production deployment on a Linux VPS using **Docker Compose, Nginx, HTTPS, PostgreSQL, and Redis**
- Configured **GitHub Actions CI/CD workflows** for automated validation, build, and deployment
- Collaborated with a backend developer responsible for server-side services and core business logic

> The source code is private because the system was developed for a commercial client.


#### ✈️ Voyage — AI-Powered Travel Booking Platform

A graduation project that combines flights, hotels, tours, and travel packages within a unified booking platform.

- Contributed to frontend development and REST API integration
- Implemented booking workflows, user-session interfaces, and personalized interactions
- Supported frontend integration for an AI chatbot connected to booking and user-history data
- Worked within a team using **React, Vite, Spring Boot, Spring Security, JWT, MySQL, Redis, and Google Maps API**


#### 🏨 Savoy — Hotel Booking System

A full-stack hotel reservation platform with real-time room browsing, booking workflows, and an administration dashboard for managing room inventory.

**Tech Stack:** React, Node.js, MySQL


#### 🛒 Mini Amazon — Multi-Vendor Marketplace

A multi-role e-commerce platform with separate interfaces for administrators, merchants, and customers.

- Developed the frontend using React
- Built product browsing, cart management, role-based dashboards, and order workflows
- Integrated frontend components with backend APIs developed using **Laravel and PostgreSQL**
